# Spire Bot（中文说明）

一个会玩《杀戮尖塔》的神经网络：铁甲战士，最高进阶 20，目标是打赢第四幕的心脏。它在你自己的游戏里打：你带 mod 启动游戏，机器人从主菜单自己开一局，一直打到这一局结束。

包里没有任何游戏文件，你需要有 Steam 上的《杀戮尖塔》。

## 需要什么

- 《杀戮尖塔》（Steam）。Windows 10/11 64 位，或 Apple 芯片的 Mac（macOS 13 或更新）。
- 存档要满足三条：**第四幕已解锁**；**铁甲战士的牌全部解锁**；铁甲战士解锁了你想让它打的进阶等级（默认 20）。机器人启动时会检查，缺哪条会写在 `logs/bot.log` 里，然后不打。
- 没有没打完的铁甲战士存档。机器人开新局会把它冲掉，所以主菜单上铁甲战士有“继续”时它不开局。
- 不要同时开会改牌、遗物、怪物或事件的其他 mod，机器人只认识原版游戏。

## 从 Steam 创意工坊安装（Windows 和 Mac）

1. 在《杀戮尖塔》的 Steam 创意工坊订阅 **ModTheSpire**、**BaseMod**、**Communication Mod** 和 **Spire Bot**。Spire Bot 自带 Python、模拟器和模型，不用解压，也不用运行任何脚本。
2. 在 Steam 启动游戏，选 **Play With Mods**。在 ModTheSpire 窗口里勾上 **BaseMod**、**Communication Mod**、**Spire Bot**，点 **Play**。
3. 到主菜单后几秒钟，机器人会自己开一局。它打的时候不要点鼠标、按键盘。

Communication Mod 自己的 `command` 设置请留空：Spire Bot 会自己启动它的程序；Communication Mod 设了别的程序时，Spire Bot 不启动（两个程序会同时给游戏发命令，面板上会说明）。日志在 ModTheSpire 的设置目录下的 `spirebot/logs`（Windows 是 `%LOCALAPPDATA%\ModTheSpire\spirebot\logs`，Mac 是 `~/Library/Preferences/ModTheSpire/spirebot/logs`）。要改设置：把条目里 `spire-bot` 文件夹中的 `spire-bot.toml` 拷到那里的 `spirebot/spire-bot.toml`，改这份拷贝；条目自己的那份在更新时会被换掉。

以前用 zip 包装过 Spire Bot 的，先运行它的卸载（`uninstall.bat` 或 `uninstall.sh`，见[卸载](#卸载)），再订阅：游戏里只能有一份 Spire Bot。

## 用 zip 包安装（Windows）

在创意工坊订阅过 Spire Bot 的，先取消订阅：游戏里只能有一份 Spire Bot（另外三个模组照旧订阅着）。

1. 在《杀戮尖塔》的 Steam 创意工坊订阅 **ModTheSpire**、**BaseMod**、**Communication Mod**。
2. 把 `spire-bot` 解压到任意目录，比如 `C:\spire-bot`。
3. 下载模型文件 `model.onnx`（发布页上有链接），放进 `spire-bot\models\`。
4. 先关掉游戏，再双击 `install.bat`。下载来的文件 Windows 可能会提示“Windows 已保护你的电脑”：点 **更多信息**，再点 **仍要运行**。它会找到游戏，把 `spirebot.jar` 拷进游戏的 `mods` 目录，并告诉 mod 这个目录在哪。找不到游戏时，运行 `install.bat --game "D:\你的路径\SlayTheSpire"`。
5. 在 Steam 启动游戏，选 **Play With Mods**。在 ModTheSpire 窗口里勾上 **BaseMod**、**Communication Mod**、**Spire Bot**，点 **Play**。
6. 到主菜单后几秒钟，机器人会自己开一局。它打的时候不要点鼠标、按键盘。

## 用 zip 包安装（Mac，Apple 芯片）

跟 Windows 一样，在创意工坊订阅过 Spire Bot 的先取消订阅。第 1、3、5、6 步同上。第 2、4 步：解压到任意目录（比如 `~/spire-bot`），然后在“终端”里运行：

    xattr -dr com.apple.quarantine ~/spire-bot      # 不运行这句，macOS 会拦下没有签名的下载文件
    ~/spire-bot/install.sh

运行前先关掉游戏。脚本找不到游戏时，运行 `~/spire-bot/install.sh --game "desktop-1.0.jar 所在的目录"`。

## 游戏里的小面板

屏幕右上角有一个小框，显示机器人在做什么：正在打、已暂停还是已停下。机器人停下或没有开打时，原因写在这里，和 `logs/bot.log` 里是同一条消息。

打的时候，小框里是机器人的“思考”：
- 这一步它最想选的前 5 个选项，每个一根条，条的长短就是网络给它的概率（网络在它挑选的那些选项上的打分，换成百分比）。金色高亮的那一项就是它实际做的那一步。
- 下面一行是它有多确定：最大的概率在 90% 以上是“很确定”，60% 到 90% 是“比较确定”，低于 60% 是“在纠结”。
- 再下面一行小字：模型有多少参数，这一步算了几毫秒。
- 选项用游戏里的名字；同名的两只怪按从左到右编号（怪名后面加 1、2），名字还是一样的选项后面加括号编号。
- 最底下的小折线是“AI 自我感觉”：网络的估值头对这一局前景的估计，画最近 20 步决定（战斗里每出一张牌也算一步），最新的一步在最右边。高低按这 20 个点自己的最高和最低拉满，所以起落看得清；竖线是一幕的分界。线只表示高低，不是胜率；第一幕开头它自己也还分不清好坏。（用的模型文件里没有估值头的话，这条线不画。）

- **F9** 暂停和接着打。已经发出去的那一步会做完，之后不再操作，直到你再按 F9。暂停时不要自己操作：游戏要是被改得机器人跟不上，它会停下，请你自己把这一局打完。
- **F8** 隐藏和显示面板。
- **F7** 在“思考”视图和只写前 3 个选项的简单视图之间切换。

面板跟着游戏语言显示中文或英文。想完全关掉，在 `spire-bot.toml` 里加一行 `panel = "0"`；只想要简单视图，加一行 `viz = "0"`。

## 设置

包目录里的 `spire-bot.toml`（从创意工坊装的：ModTheSpire 设置目录下你的那份拷贝，见上）：模型文件名、进阶等级、种子（留空就每次随机）。换模型：把新的 `.onnx` 文件放进 `models/`，把 `model = "..."` 改成它的文件名。

## 打的时候和打完以后

- `logs/bot.log` 写着机器人在做什么；它不打的时候，原因也在这里。
- 每一局在 `logs/` 下留一个文件夹，里面是每一步的游戏局面和命令。这些只留在你的电脑上，不会发到任何地方，内容只有游戏局面。
- 机器人开的局是指定种子的局，和你自己输入种子开的局一样。
- 机器人打的局就是你这个存档的普通对局：会出现在历史记录里，也计入统计数据。
- 一局打完机器人就停。想让它再打一局，重启游戏。
- 想自己玩：不带 mod 启动游戏，或者不勾 Communication Mod 和 Spire Bot。

## 卸载

从创意工坊装的：取消订阅。用 zip 包装的：运行 `uninstall.bat`（Windows）或 `uninstall.sh`（Mac），再删掉这个目录。它会把 `spirebot.jar` 从游戏里删掉，也删掉 mod 记的目录位置；如果旧版本的机器人改过 Communication Mod 的 command，会把它的设置还原成改之前的样子。

## 出问题时

- 主菜单上什么都没发生：看右上角的面板和 `logs/bot.log`。面板显示“Spire Bot 没有启动”时，要么是 Communication Mod 设了别的程序（把它的 `command` 清空），要么是找不到机器人自己的文件夹（重新订阅，或重新运行安装脚本）。
- 打到一半停了：游戏里出现了机器人的模拟器跟不上的情况。原因在 `logs/bot.log`；报告问题时请附上 `logs/` 里这一局的文件夹。
- Windows 上 `logs/bot.log` 说有一个库加载不了：安装微软的 Visual C++ 运行库 https://aka.ms/vs/17/release/vc_redist.x64.exe ，再重新启动游戏。

## 这一版已知的限制

- **Windows 包还没有在 Windows 电脑上实际运行过。** 它是在 Mac 上做出来、检查过的：同样的桥接、模型和模拟器代码在 Mac 上打过真游戏；Windows 的模拟器模块只做了静态检查（它只依赖包里自带的 Python 和系统库）。没有在 Windows 上亲眼看到能用的有三处：模拟器模块能不能加载、安装脚本能不能找到游戏、从 Steam 的 Play With Mods 启动器启动。机器人没启动时，`logs/bot.log`（或者没有这个文件）和 ModTheSpire 的日志窗口能看出停在哪一步，欢迎反馈。
- Windows：`logs/bot.log` 说有库加载不了，就是缺微软的 Visual C++ 运行库（见“出问题时”）。
- 只在简体中文的游戏里测过。其他语言应该能用（机器人认的是 ID，不是名字），但没打过。
- F9 在 Mac 上的真游戏里按过（能暂停、能接着打）；F8 和 F7 只直接调用验证过，还没有在键盘上按过。Mac 笔记本上默认要按 Fn+F9、Fn+F8，除非系统设置里把功能键设成了标准功能键。
- 战斗里某些选牌之后，机器人要先算出游戏接下来发牌的顺序。通常不花时间；见过最慢的一次，游戏会停 10 秒左右再接着打（电脑慢的话会更久）。
- 战斗开头机器人会短暂等怪的意图出现，最多约 5 秒；带 Runic Dome（符文圆顶，看不到意图）时固定等半秒。
- 每次启动游戏打一局。游戏里偶尔出现模拟器跟不上的情况，机器人会停在半路；重启游戏开新的一局。

## 技术说明

- 网络给每个合法选项打分，机器人取分数最高的。分数和最高分相差不到 0.0001 的选项算平手，取排在最前面的那个：等价的选项（比如两张一样的牌）分数只在最后几位上有差别，而这几位在不同电脑上不一样；加这条规则是为了让机器人在每台电脑上选的都一样。
